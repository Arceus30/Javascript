# JavaScript Practice Repository

## Introduction

This repository contains my JavaScript learning journey, starting from the fundamentals and progressing to more advanced concepts. Each file focuses on a specific topic, with examples and small projects to reinforce understanding.

Topics covered include:

- Variables
- Data Types
- Type Conversion
- Comparison Operators
- Strings
- Numbers & Math
- Dates & Time
- Arrays
- Objects
- Functions
- Scope
- Arrow Functions
- Conditionals
- Loops
- DOM Manipulation
- Events
- Asynchronous JavaScript
- XMLHttpRequest
- Promises
- Fetch API
- Prototypes
- Classes
- Inheritance
- `call()`, `bind()`
- Closures
- Getters & Setters
- Math APIs
